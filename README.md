# Shot-Shot-Shot (PT)
Este é o primeiro jogo que eu fiz usando Python. Simples, mas funciona perfeitamente.
## Como Jogar:
Setas do teclado para mover, espaço para atirar. Os inimigos saem do topo da tela. Não os deixe atingir a parte infeiror dela.

# Shot-Shot-Shot (EN)
This is the first game that I made using Python. Simple, but works perfectly.
## How to Play:
Arrow keys to move, space bar to shoot. The enemies appear at the top of the screen. Don't let them hit the bottom.
